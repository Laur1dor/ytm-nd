# ytm-sync

ytm-sync is a personal, self-hosted tool that copies newly liked YouTube Music
tracks into a playlist owned by the same account. It then synchronizes that
playlist with a local music library. It never removes tracks from the liked
playlist or the destination playlist.

Source code and setup: [Laur1dor/ytm-nd](https://github.com/Laur1dor/ytm-nd).
